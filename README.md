# 合同会社Progress｜留学生向け賃貸仲介サービス

留学生向け賃貸仲介サービスのコーポレートサイト（静的HTML・スマホ対応）。

## 内容

- サービス内容（空港送迎／アルバイト紹介協力／クレーム対応／生活・行政手続きサポート／短期滞在）
- 就職・求人のサポート（技人国ビザ／特定技能ビザ）
- サービスの特徴・料金体系
- 対応言語・国籍
- 会社概要

## 構成

- `index.html` … 単一ファイルで完結（CSS/JSインライン、Webフォントは Google Fonts）

## ローカルで確認

```bash
python -m http.server 8000
# http://localhost:8000 を開く
```
